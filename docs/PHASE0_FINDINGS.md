## 2. 시뮬레이션 과정에서 발견·수정한 구조 결함 5건 (가중치 아님)

1. **중복 탐지 임계값**: char 3-gram Jaccard 0.80은 짧은 한국어 리뷰에서 "1글자 편집 복붙(스팸)"과 "단어 치환(정상 변형)"이 둘 다 0.82~0.88에 몰려 구분 불가. 실측 결과 **bigram(n=2)** 은 복붙 0.92+ / 정상 0.82~0.86으로 분리 → `n=2, threshold=0.89` 로 확정. 정규화 16자 미만 상용구는 판단 제외.
2. **플랫폼 통계 게이트**: Σw≥3 조건은 오래된 노포(D)처럼 리뷰 가중치가 낮은 식당의 플랫폼 통계를 통째로 누락시켜 consistency=0.45(검증불가) 부여 → **리뷰 수 ≥3 기준**으로 변경.
3. **longevity 역보상**: 연도별 평점을 강한 수축(C=2)으로 계산하면 근거 적은 해가 전부 사전확률로 수렴해 sd≈0 → "증거 적을수록 안정적"이라는 역보상. **실제 연도별 가중평균의 sd**로 변경.
4. **인위적 플랫폼 일관성**: 바이럴(C)은 모든 플랫폼에서 관광객이 똑같이 높은 별점을 줘 consistency 0.93 가산을 받음 — 조작·유행이 만든 상관편향(corrrelated bias)도 검증으로 오인. **consistency × (1 − manipulation)** 할인 도입. C는 0.93→0.66으로 하락, E보다 아래로.
5. **폭발 감지 floor**: peak/중앙값 비율 4배부터 감점 시작하니 실제 폭발(C: 20/4)이 0으로 측정 → floor 2.5, span 10으로 조정.

## 3. 광고 감점의 실제 효과 (Review Weight v1)

- A(광고 45개): 단순 4.66★ → 보정 4.49★ (−0.17★), 광고 리뷰 평균 가중치 ≈ 0.11 (진성 리뷰 ≈ 0.75~0.85). p_eff≥0.7 비율 37%.

## 4. 직관과 남은 불일치 2건 분석

### 4-1. D(노포) > B(로컬 찐맛집), 격차 2.2점 — **판단 필요**

기여도 비교 (A안):

| 항목 | B | D | B−D |
|---|---|---|---|
| rating | +48.6 | +48.5 | +0.1 |
| consistency | +11.4 (3플랫폼 일관) | +10.0 (2플랫폼) | +1.4 |
| repeat | +2.1 (26%) | +2.6 (32%) | −0.5 |
| local | +4.5 | +4.2 | +0.3 |
| **longevity** | **+2.2** (1.6년) | **+5.7** (6년 안정) | **−3.5** |
| trust | +7.8 | +7.3 | +0.5 |

격차의 전부는 longevity(D +3.5). 단, B는 **근거가 D의 3배**(n_eff 20.5 vs 6.9)이고 3플랫폼에 걸쳐 있지만 현재 Overall에 "근거의 양"을 직접 보상하는 항목이 없다(수축으로만 간접 반영).

### 4-2. C(바이럴) > A(광고다수), 격차 7.8점 — **직관 재검토 권고**

A가 C보다 아래인 이유: manipulation −6.8 vs −3.3, trust 56 vs 65, consistency 29 vs 66(A는 광고 플랫폼과 정상 플랫폼 평점이 갈림). 스펙의 직관은 A 4위였지만, 제품 철학("돈을 쓴 식당이 아니라 실제 사람들이 만족하는 식당")에 비추면 **허위 광고로 포장된 A가 과열 관광객 반응의 C보다 아래인 것이 오히려 의도에 부합**. 직관 순위의 A/C 위치를 바꾸는 것을 권고한다.

추가 관찰 — **평점 항목의 압축**: μ_r(≈0.875) 수축(C=10)이 A의 보정평점 하락을 부분적으로 되살림. A rating 0.872 vs C 0.885로 사실상 동일. 광고 감점 효과를 평점 항목에서 더 크게 보려면 `c_rating` 10→6 조정이 유효하나, 전체 점수 분산도 같이 커지는 트레이드오프.

## 5. 가중치 조정 옵션 (확정은 사용자 결정)

| 옵션 | 변경 | 예상 효과 (A안) | 비고 |
|---|---|---|---|
| **1. 근거 강도 항목 신설 (권장)** | `evidence = min(n_eff/20, 1)` 항목 추가(+6점), 기존 항목 합계 100→94로 재조정 | B +6.0, D +2.1 → **B가 1위** (약 +1.7 차) | "많고 분산된 근거"를 직접 보상. 노포 철학 훼손 없음 |
| 2. longevity 축소 | 7 → 5 (A안) | D −1.6, B −0.6 → 격차 1.2 (D 우위 유지) / 4로 줄여야 B 역전 | 노포 보상 약화, 비권장 |
| 3. c_rating 축소 | 10 → 6 | A 보정평점 추가 −0.01~0.02, 전체 분산 확대 | 광고 감점 가시화. 1번과 병행 가능 |
| 4. 현행 유지 | 없음 | D>B (2.2점 차) 유지 | "6년 안정 노포 ≥ 검증된 로컬"도 합리적 해석 |

Version A vs B: **순위 변화 없음**. B안(평점 45%)은 하위권(A/C) 분리만 강화(trust 13%가 A의 낮은 신뢰도를 증폭). 당분간 A안 기본 유지 권고 — 실데이터 확보 후 재비교.

ad_prior 민감도: 0.2 / 0.3 / 0.5 모두 순위 불변 → 목 분석기 conf 0.5~0.95 범위에서 prior 영향이 작고 안정적. 실 GLM에서 conf 분포가 낮게 나오면 재검증 필요.
